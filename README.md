# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Описание проекта
Сайт программы развития инженеров спортивных автомобилей «RaceCraft Engineering». 
Проект выполнен на CSS-фреймворке Bootstrap 5 и адаптирован под мобильные устройства.

## Используемый фреймворк
Bootstrap 5.3.3.
Подключение выполнено через CDN (в `<head>` для CSS, перед `</body>` для JS Bundle).

## Структура проекта
- `index.html` — Главная страница (hero-блок, преимущества, направления, события).
- `catalog.html` — Программа обучения (учебные треки, таблица достижений, FAQ-аккордеон, модальное окно).
- `product.html` — Справочник (подробное описание всех треков и направлений с якорной навигацией).
- `order.html` — Заявка на обучение (форма с валидацией и калькулятором стоимости).
- `css/custom.css` — Кастомные стили (гоночная тема, переопределение цветов Bootstrap).
- `images/` — Папка для изображений.

## Реализованные компоненты Bootstrap
В ходе выполнения работы были использованы следующие компоненты:
- **Сетка:** `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, утилиты отступов `g-*`, `my-*`, `p-*`.
- **Навигация:** `navbar`, `navbar-toggler`, `collapse`, `breadcrumb`.
- **Карточки и кнопки:** `card`, `btn` (варианты `btn-danger`, `btn-outline-danger`, `btn-outline-secondary`), `badge` (метки «Новинка», «Хит», «Скидка»).
- **Формы:** `form-control`, `form-select`, `input-group` (для телефона), `form-check` (чекбоксы).
- **Интерактивные элементы:** `modal` (быстрая заявка), `accordion` (FAQ), `alert` (информационные сообщения).
- **Таблицы:** `table`, `table-responsive`.

## Самостоятельные доработки (сверх базовой инструкции)
Для повышения оценки были реализованы следующие улучшения:
1. **Единый дизайн:** Разработана кастомная «гоночная» цветовая схема (красно-черная) с переопределением стандартных цветов Bootstrap в `custom.css`.
2. **Эффекты при наведении:** Карточки и кнопки плавно приподнимаются и отбрасывают тень (`transform`, `box-shadow`).
3. **Калькулятор стоимости:** На странице `order.html` реализован динамический подсчет итоговой цены при выборе трека и дополнительных опций (с использованием JavaScript).
4. **Валидация форм:** Добавлены атрибуты `pattern` для проверки корректности ввода имени (только буквы) и телефона (только цифры и спецсимволы).
5. **Универсальный справочник:** Страница `product.html` объединяет треки и направления, используя якорные ссылки (anchor links) для быстрого перехода.
